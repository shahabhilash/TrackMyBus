# TrackMyBus

TrackMyBus is a modern web application built with React, Vite, and Tailwind CSS. It is designed to provide real-time bus tracking and scheduling information.

## Getting Started

### Prerequisites

Ensure you have Node.js installed on your system.

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

### Running the App

To start the development server:
```bash
npm run dev
```

## Technologies Used
- React
- Vite
- Tailwind CSS
- Lucide React
